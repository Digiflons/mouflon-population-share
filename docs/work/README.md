# Work files

The team keeps one shared work file per piece of work here (`<yyyy-mm-dd>-<slug>.md`, made from [`TEMPLATE.md`](TEMPLATE.md)): the brief, the design, the threat model, decisions, test and review notes.

The work files of past work are internal and are not part of this shareable copy. The decisions that last are recorded in the docs themselves: [architecture](../architecture/README.md), [security](../security.md), [testing](../testing.md) and the App's [changelog](../../app/CHANGELOG.md).
